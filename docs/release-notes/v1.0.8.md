## CometChat removed entirely

Every CometChat package is gone — `@cometchat/chat-uikit-react-native`, `chat-sdk-react-native`, `calls-sdk-react-native`, `push-notifications-react-native` — along with 93 files that depended on them. Calling, messaging, auth, theming and push now run entirely on **Convex + react-native-webrtc + react-native-paper**.

| | Before | After |
|---|---|---|
| JS bundle | 8,746,133 B | **2,764,595 B** (−68%) |
| Release APK | 121 MB | **59 MB** (−51%) |
| Own-code TypeScript errors | 30 | **0** |

### Chat media
- **WhatsApp-style sending** — the message appears immediately with its timestamp and a progress indicator, uploading in the background. The composer clears at once and a slow upload never blocks the next message.
- **Video no longer downloads the whole file.** The real cause was the poster `<Image>` being pointed at the mp4 URL, so Fresco fetched every byte trying to decode it as a picture. Now a proper streaming buffer, plus play/pause, progress and fullscreen.
- **Swipe to reply** — right on an incoming message, left on your own; does not fight scrolling, long-press or tap.

### Theme
The UIKit handed both `light` and `dark` the *same* colour object, so screens using it never followed the OS scheme. Fixed at the root.

### Profile and settings
App and links cards moved out of Profile into Settings. Four duplicated rows removed. The chat list header shows the app name; the redundant profile button is gone.

### Fixes
- Add-contact search was leaking a raw `[CONVEX Q(...)] Uncaught Error: …` string to the user. Now friendly, specific copy.
- `react-native-vision-camera` removed — it served only the deleted QR scanner.
- **The release pipeline had been broken since v1.0.0.** Installing the CometChat UIKit on macOS baked 881 of 2,045 lockfile entries from a cloned example app into `package-lock.json`; its darwin-only `fsevents` entry made `npm ci` fail on every Linux runner.
