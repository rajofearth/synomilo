# Port plan: dead CometChat features -> live Convex

Decision: **port, don't delete** (user's call). Working notes condensed from three
read-only mapping agents. Everything here cites `file:line`.

## Why port first, not delete

The ported features live in `convex/` (the shared backend). The planned Next.js web app
consumes the same backend, so **every feature ported now is inherited by the web app for
free**. Deleting instead would lose the capability on both platforms.

## Reachability (verified by hand, not just by the audit)

Live stack: `Login`/`SignUp` (release `initialRouteName`) -> `BottomTabNavigator`
(Chats=`convex/ConversationsList`, Calls=`calls/Calls`, Users=`convex/UsersList`) ->
`Messages`=`convex/ChatScreen` -> `ForwardMessage`, `ChatInfo`/`ContactInfo` (`ChatScreen.tsx:712`),
`CallScreen`, `Profile`, `Settings`, `Groups`=`convex/GroupsList`, `OngoingCallScreen`.

Everything else is registered in `RootStackNavigator.tsx` but reachable from nowhere:
`Conversation`, `CreateConversation`, `SearchMessages`, `ThreadView`, `SavedMessages`,
`PinnedMessages`, `UserInfo`, `GroupInfo`, `AddMember`, `TransferOwnershipSection`,
`BannedMember`, `ViewMembers`, `CallDetails`, `CallLogs`(route), `QRScreen`, `AIAgents`.

### Features that do NOT exist and are therefore not ports
- **Report user**: zero hits for "report" across `src/` and `convex/`. Net-new, not a port. Skip.
- **Kick/ban with reason**: the CometChat SDK signature is `kickGroupMember(guid, uid)` /
  `banGroupMember(guid, uid)` (`CometChat.d.ts:1998,2017`) — no reason param, and the UIKit
  confirm modal has no reason input. There is nothing to port.

## Schema gaps (convex/schema.ts)

`members.role` is `owner|member` only (`:43`) — blocks promote/demote and the admin/moderator
gates the dead screens used. No `bans`. No `bannedUserIds`. No block state on `users`.
`messages` has only `replyToId` (`:68`) — no `parentId`, no `replyCount`, no `pinnedAt`, no
`searchText`. No `savedMessages` table (save is per-user, so it cannot live on `messages`).

## Known backend defects to fix while porting
1. `conversations.addMembers` (`:236`) checks membership but **not** `role === "owner"` — any
   member can add strangers. Confirmed IDOR.
2. `conversations.typing` (`:411`) has **no membership check** — any logged-in user reads any
   conversation's typing roster. Confirmed IDOR.
3. `conversations.leave` (`:381`) has **no ownership check** — an owner can orphan a group.
   The dead UI prevented this (`GroupInfo.tsx:433`); move the guard server-side.
4. `files.url` (`convex/files.ts`) discards its auth helper result — signed URL for any
   `storageId`. Confirmed IDOR.
5. `messages.send` `replyToId` is never validated against the target conversation, and
   `messages.list:106` returns the foreign message body. Confirmed leak.
6. `updates.publish` gates on a hardcoded username with no role column. Remote code execution.
7. Block must be **enforced**, not cosmetic: gate `messages.send`, `calls.start`, `createDM`.

## ChatScreen cross-cutting traps
- `actionCount` (`:1066`) is `3 + copy? + delete?` and drives `estimatedMenuHeight` (`:1071`) ->
  `menuTop` (`:1075`). **Every menu row added must bump the base**, else the menu overflows the
  screen. This breaks silently.
- `limit: 60` hardcoded at `:256`; `hasMore` (returned by `convex/messages.ts:164`) is discarded
  at `:297`. No `onEndReached`. Search, Saved, Pinned and Threads all assume history can load —
  wire pagination first.
- `route.params` is read at `:244` for `conversationId`/`title` only — a `messageId` param is
  ignored, so Saved/Pinned/Search taps cannot deep-link.

## Ordering
1. Pagination + `actionCount`/`menuTop` fix (unblocks everything else).
2. Schema additive changes. **Do NOT rename `by_conversation_createdAt`** — add the parent index
   alongside it. A rename breaks 5 call sites (`messages.ts:37,331`,
   `conversations.ts:61,341,464`) for no gain.
3. Backend mutations per cluster, each with an ownership check.
4. UI per cluster, then delete that cluster's dead files + route registrations.
5. Update `src/navigation/types.ts` alongside — it declares params for 15 routes that will no
   longer exist.
